# Tala Alyousef — portfolio

Static site: plain HTML, CSS, and a little JavaScript. No build step.

- `index.html`, `work.html`, `design.html`, `about.html`, `contact.html`, `404.html`
- `css/base.css` — shared layout. `css/theme-a.css` — colors and fonts (swap this file to restyle).
- `js/main.js` — Design page filters and image viewer.
- `assets/img/` — images. `assets/fonts/` — Famely.

Preview locally by opening `index.html`, or serve the folder with any static server.
